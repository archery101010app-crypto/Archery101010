Tiendas de Apps

Requisitos Obligatorios para Publicación

⚖️ Políticas y Términos Legales

Es obligatorio para ambas tiendas contar con una URL pública con las Políticas de Privacidad y Términos de Servicio. Generados mediante plataformas online gratuitas bajo tu dominio corporativo.

⚙️ Eliminación de Cuenta y Datos

Las directivas exigen que si un usuario se registra en la app, debe contar con un botón dentro del perfil para borrar su cuenta y eliminar sus datos de la base de datos de manera definitiva.

🎨 Íconos y Splash Screen Adaptativos

Reemplazar los logos rectangulares por assets cuadrados e íconos adaptativos maskables en múltiples resoluciones (192px, 512px y 1024px) para evitar distorsiones en las tiendas de Android e iOS.

🔒 Seguridad de Credenciales

Eliminar del código expuesto todas las API Keys de Firebase y credenciales de administrador general, moviéndolas a variables de entorno (.env) seguras.
